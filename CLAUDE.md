# open-lens-site — Claude context

Two-page GitHub Pages site (Jekyll, `jekyll-theme-minimal`) for the OpenLens
iOS app: homepage (`index.md`) and privacy policy (`privacy.md`). This repo is
intentionally **public**; the app's code lives in the private `open-lens` repo.

The page URLs are registered on the Google OAuth consent screen (project
`openlens-513703`, Branding page). Renaming the repo or files breaks them.
If the app's data handling changes, update `privacy.md` here and bump its date.

## Conventions

This repo follows the account-wide conventions in `~/code/machine-setup/CONVENTIONS.md`.
